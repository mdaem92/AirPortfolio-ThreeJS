# About screen and boarding-pass entry

Implemented the approved information-screen direction as native HTML/CSS on the existing LCD. Its model dimensions are 2.845 × 3.015 world units, so the original landscape mockup was rearranged into a slightly portrait 760 × 805.4 design. It retains the dark navy/ivory/amber palette, terminal identity, gate A1, topic labels, subtle terminal map and Back to departures button.

The approved About paragraph is retained, with an additional paragraph mentioning AI-assisted development and workflow automation. Blender is not mentioned. Narrow screens use larger text and a vertically scrollable reading area, with a fixed header and back footer. The camera fits the physical LCD to both viewport dimensions.

The opening START link is replaced by a responsive cream boarding pass, with perforations, a decorative barcode, flight MY 101 and gate A1. Its shorter introduction includes software engineering, 3D, interactive experiences, AI-assisted development and workflow automation. Start exploring is a real keyboard-accessible button. It is disabled until the scene is ready; audio activation remains behind this explicit action. The ticket remains visible with loading feedback while assets load. The stub stacks below the main ticket on phones, and the full overlay can scroll on short screens. Reduced motion disables transitions.

The About screen uses the same depth-blended Html approach as the welcome board. It mounts while About is focused or when looking around, and unmounts for the main focus and other sections. Dedicated wrapper overflow:clip prevents browser scrollIntoView from scrolling the perspective layer and displacing the visible screen. Screen clicks do not propagate to underlying 3D controls; the original LCD click target is disabled during About focus. Shared model resources remain unchanged.

Validation: 23 tests pass, including Start readiness/StrictMode/audio gating, the About back action, and the approved lighting defaults. Production build, lint and asset verification pass. Browser checks cover desktop and 390 × 844 entry layouts, matching the physical About frame, no text clipping on desktop, scrollable mobile reading, Start navigation and pointer/keyboard return. No new dependencies, remote fonts or runtime images. The large generated concept images remain design references in output/design-concepts/about-me and are not loaded by the app. Approved for commit and push on 2026-11-01; production deployment is separate.
